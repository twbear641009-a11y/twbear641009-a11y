## 👷 關於我

我是 **Ching Chun Lin**，一位擁有 30 年現場經驗的資深工地主任。

長年待在第一線，我很清楚工地管理哪裡最耗時、哪裡最容易出錯。CL Labs 是我把現場實務整理成數位工具的地方：讓資訊清楚、流程順暢，把時間還給真正重要的工作。

> Senior construction site manager with 30 years in the field, now building the tools I always wished I had on site.

## 📐 為什麼叫 CL

**CL** 取自建築圖面上的**中心線（Center Line）**。所有尺寸與定位都從中心線開始，CL Labs 的每一項工具也一樣：先找到基準，再把事情做準。
